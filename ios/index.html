COSC 559 – Bakeoff 3

Open a prototype, then use Share → Add to Home Screen to run it full-screen.

1. Handwriting Enter Draw a letter, then tap ENTER 2. Expandable Groups Pick a letter group, then a letter 3. Circular Keyboard Tap or slide around the ring 4. QWERTY Swipe Tap keys, or swipe and pause on each letter 5. Press & Drag Circular Hold the center, drag to a letter, release

The gray input square should measure 1″ with a ruler. If it doesn't, add ?ppi=163 (or your device's points per inch) to a prototype's URL. Add ?trials=10 to change the number of phrases.
